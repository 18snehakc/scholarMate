# 🎓 ScholarMate – Smart Scholarship Discovery Platform

### Find the Right Scholarship. Build Your Future.

ScholarMate is a web-based scholarship discovery platform designed to help students easily find scholarship opportunities based on their academic performance, financial background, category, and location.

The platform simplifies scholarship discovery by bringing scholarship information, eligibility details, student profiles, and application deadline tracking together in one place.

## 🎯 Problem Statement

Many students are unaware of available scholarship opportunities due to scattered information, complicated eligibility requirements, and missed application deadlines.

ScholarMate aims to make scholarship discovery easier, faster, and more accessible for students.

## 🚀 Key Features

- **Scholarship Search:** Search and explore available scholarships.
- **Category-Based Filtering:** Explore Government, Merit-Based, and Need-Based scholarships.
- **Student Profile Management:** Save academic, financial, and category information.
- **Location-Based Search:** Find scholarships based on state and district.
- **Scholarship Details:** View scholarship eligibility requirements and required documents.
- **Application Tracker:** Track scholarship application progress and deadlines.
- **User-Friendly Interface:** Simple and responsive design.

## ⚙️ Installation and Execution

### 1. Clone the repository

```bash
git clone https://github.com/18snehakc/scholarMate.git
```

### 2. Navigate to the project folder

```bash
cd scholarMate
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

```text
http://localhost:3000
```
